# PakAutoHub ko Android aur iPhone par install karein

## Android

1. Chrome mein live app kholein: https://pakautohub-aaiez.sagetoad8.chatgpt.site
2. Website ka Install app button tap karein.
3. Install confirm karein. Prompt na aaye to Chrome ke teen dots wale menu se Install app / Add to Home screen choose karein.
4. PakAutoHub icon se app kholein aur pehli baar internet on rakhein.

## iPhone

1. Live app ka link Safari mein kholein.
2. Share button tap karein. Kuch Safari layouts mein Share page menu ke andar hota hai.
3. Add to Home Screen choose karein.
4. Open as Web App option dikhai de to on karein aur Add dabayein.
5. Home screen par PakAutoHub icon se app kholein; pehli baar internet on rakhein.

## Offline

Installation guide mein Offline catalogue ready dikhne ke baad catalogue, comparison aur budget calculator offline chal sakte hain. External listing photos aur source links ko internet chahiye. Prices dated snapshot hain. Saved cars aur budget inputs isi browser/app mein rehte hain; doosre device par automatically sync nahin hote.

## Apni GitHub/Vercel website update karein

ZIP extract karein, PakAutoHub_Phone_App folder ki sari files aur subfolders repository mein upload/replace karein, commit aur push karein. Vercel mein index.html wala folder root choose karein. Framework Other, Build Command override on aur khali, Output Directory . rakhein. Deploy ke baad apne Vercel link se bhi app install ho jayegi.

Yeh installable web app (PWA) hai. Python ki file sirf optional laptop server hai; app ki coding HTML, CSS, JavaScript aur manifest/JSON mein hai. Aage app ya car data edit karne par sw.js mein CACHE_VERSION ko naya value dena zaroori hai.
